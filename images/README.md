# Imagem de Compartilhamento Social (OpenGraph & Twitter Card)

Este diretório contém a imagem oficial de compartilhamento social do catálogo da **RJ Móveis**.

## Arquivo Oficial: `og-share.jpg`

- **Finalidade:** É a imagem exibida automaticamente em pré-visualizações quando um link do site é compartilhado no **WhatsApp**, **Facebook**, **Instagram**, **LinkedIn**, **Twitter/X**, **Telegram** e outras plataformas.
- **Dimensões Recomendadas:** 1200 x 630 pixels (proporção 1.91:1) ou 1920 x 1080 pixels (proporção 16:9).
- **Formato:** JPG ou PNG de alta qualidade.

## Como Substituir por uma Foto Própria:
1. Prepare a sua imagem desejada (idealmente com boa iluminação e composição centralizada).
2. Salve o arquivo com o nome exato: `og-share.jpg` dentro desta pasta (`images/`).
3. Ao enviar o commit e push para o repositório, todas as 8 páginas do catálogo passarão a utilizar a sua nova imagem automaticamente.
